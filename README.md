# Nitish Kumar Tiwari — Portfolio

A multi-page, responsive personal portfolio built with semantic HTML5, modern CSS3 and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About, education and skills
- `projects.html` — Selected projects
- `contact.html` — Contact form demo

## Design features
- CSS Grid for page and project layouts; Flexbox for navigation, actions and skill tags.
- Mobile-first responsive layouts with tablet/desktop enhancements.
- CSS custom properties for colors, surfaces, spacing and theme tokens.
- Persistent light/dark theme toggle (uses local storage when available, otherwise follows system preference).
- Accessible navigation controls, visible keyboard focus, skip link and reduced-motion support.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish on GitHub Pages
Upload the contents of this folder to your GitHub repository. In **Settings → Pages**, select the deployment branch and root folder, then save. GitHub will provide the published URL.

## Contact form note
The form currently validates input in the browser only. Connect a backend or form service before using it to receive messages.
